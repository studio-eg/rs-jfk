# Realschule John-F.-Kennedy-Platz

> Eigenverantwortliches und kooperatives Lernen in einer gewaltfreien Schule.

## About this project

This is a from-scratch rebuild of [rs-kennedy.de](https://rs-kennedy.de/index.html), the real website of the Realschule John-F.-Kennedy-Platz in Braunschweig, Germany. All school facts (address, contact, leadership, programs, history) were researched directly from the live site. The visual design was rebuilt to feel modern, classic, and professional — not a copy of the original template — while deliberately keeping the identity elements that make the school recognizable.

## Brand Identity

- **Personality:** Trustworthy, structured, academic, welcoming. A public German Realschule — not a startup or SaaS product.
- **Preserved from the original site:** the coral-red accent color, the plain-text wordmark (the school has no graphic logo/crest), and the photography-and-storytelling driven "Schulleben" news content.
- **Modernized:** cleaner grid layouts, more whitespace, a serif display typeface for gravitas, and a restrained neutral palette instead of the original's dated free-template look.

### Colors
- Background: `#faf8f5` (warm off-white)
- Surface (cards): `#ffffff`
- Foreground/text: `#262220` (warm off-black)
- Muted text: `#6b6259`
- Border: `#e7e1d9`
- Accent (from the original site's link/button color `#e0555a`, deepened for a more institutional feel): `#ac3b32`, hover `#8c2f28`
- Ink (dark sections — header banner, footer): `#262220`

### Fonts
- Display/headings: **Fraunces** (serif — gives the academic, classic gravitas the brief asked for)
- Body: **Lato** (the same typeface the original site used — keeps continuity)

### Logo
The original school has no graphic logo, only a text wordmark. The rebuild adds a simple circular "JFK" monogram in the accent color next to the wordmark "Realschule John-F.-Kennedy-Platz" — a light identity mark, not a redesigned crest.

## Content management (CMS)

Nearly everything on the site is now editable by you, without needing a developer, through a built-in admin panel — powered by **Payload CMS**.

**How to edit your site:**
1. While the preview is running, go to `/admin` (e.g. `localhost:3000/admin` in Ship Studio, or `yoursite.com/admin` once deployed).
2. The first time, you'll be asked to create an admin account (email + password) — this is your login, not shared with anyone.
3. In the sidebar you'll see:
   - **Posts** — the 15 (and counting) Schulleben blog stories. Edit any post, or click "Create New" to add one — just fill in a title, pick a tag, write the text, and upload a photo.
   - **Pages** — brand-new pages you build yourself from reusable sections (see "Reusable sections / page builder" below).
   - **Media** — every photo used on the site. Uploading here makes an image available to use elsewhere (e.g. in a Post).
   - Under a **Globals** section: one entry per page — **Home**, **Schulprofil**, **Angebot**, **Organisatorisches**, **Personen**, **Kontakt**, **Impressum**, **Datenschutz** — plus **Header**, which holds the top navigation bar (see below). Each one holds that page's editable text, images, and lists (e.g. the Kontakt global holds the school's address/phone/email, and it automatically updates the footer and — once relevant — Impressum too, since they all show the same contact info).
4. Click any field, change it, click **Save** (for a Global) or **Save & Publish** — the change shows up on the live site right away.

### Reusable sections / page builder

Every page now has an extra field near the bottom of its editor called **"Zusätzliche Bausteine"** (additional building blocks). This is a small library of ready-made, reusable sections you can add without any code:

- **Text & Bild** — a heading, paragraph, and photo side by side (photo left or right)
- **CTA-Banner** — a colored call-to-action banner with a button
- **Zitat** — a large quote, with an optional name/role/photo
- **Zahlen & Statistiken** — a row of highlighted numbers with labels
- **Bildergalerie** — a grid of photos with captions
- **FAQ / Fragen & Antworten** — a click-to-expand question list
- **Personen-Übersicht** — a grid of people (name, role, email, photo) — same style as the Personen page
- **Freitext** — plain rich text for anything else

You can add any of these to the bottom of **any existing page** (they appear after that page's normal content), and you can also click **Pages → Create New** to build a **whole new page from scratch** — give it a title and web address (e.g. `elternbeirat` → `yoursite.com/elternbeirat`), then stack as many of these sections as you like. New pages are NOT automatically added to the top navigation menu — go to **Header** under Globals and add a nav item yourself (see "Navigation bar" below), or just ask.

Reserved web addresses (`kontakt`, `angebot`, etc. — anything already used by an existing page) are blocked when creating a new page, so you can't accidentally create a page that's unreachable.

### Navigation bar

The top navigation bar (logo text, the 7 nav links, and the two buttons — "Stundenplan" and "IServ-Login") is fully editable under **Globals → Header**:
- **Logo image** — the small mark shown to the left of the wordmark (replace it any time by uploading a new image to the "Logo Image" field; falls back to the original "JFK" circle if cleared).
- **Logo text** — the "Realschule" eyebrow and "John-F.-Kennedy-Platz" wordmark.
- **Nav-Links** — add, remove, reorder, or relabel entries. To link to a page you created yourself, type its web address into the link field (e.g. `/elternbeirat`); check "external" for links that leave the site.
- **Buttons** — the outlined button (Stundenplan) and the solid accent button (IServ-Login) each have their own editable label and link.

Changes here update both the header and the footer's navigation column at once, and show instantly with Live Preview.

**Live Preview — see your changes as you type:** every page (all 8 Globals plus every Schulleben Post) now has a **Live Preview** toggle at the top of its edit screen, next to the "Edit" tab. Turn it on and a preview of the real page appears right next to the form — as you type in a field or change an image, the preview updates instantly, before you even click Save. Use the device-size buttons in the preview toolbar to check how it looks on mobile/tablet/desktop.

**What's editable vs. what stays fixed in code:** almost all text, images, and list items (Leitziele, Ausstattung, Fachbereiche, AGs, Gremien, etc.) are editable in `/admin`, including the top navigation bar now (see "Navigation bar" above). A few things are intentionally left as code, not content, because they're structural: the footer's legal link list (Impressum/Datenschutz, `lib/nav.ts`), the Organisatorisches page's sticky quick-nav (its 4 section jump-links are wired to fixed anchors in the page, so editors can't accidentally break them), and the small icon graphics used on the Schulprofil "Ausstattung" tiles (you pick *which* icon from a dropdown, but the icon shapes themselves aren't editable).

**Where the CMS lives in the code** (for reference, not something you normally need to touch):
- `payload.config.ts` (project root) — the main CMS configuration.
- `payload/collections/` — Posts, Media, Users, Pages (the repeatable content types).
- `payload/globals/` — one file per page's editable fields (Home.ts, Schulprofil.ts, etc.), plus `Header.ts` for the top navigation bar.
- `payload/blocks/` — the reusable "Zusätzliche Bausteine" section library (Text & Bild, CTA-Banner, Zitat, etc.), shared by every page and by `payload/collections/Pages.ts`.
- `components/blocks/` — the matching React components that render each block type, plus `BlockRenderer.tsx` which picks the right one.
- `lib/payload.ts` — the functions each page uses to fetch its content from the CMS.
- `payload/livePreview.ts` — shared settings for the Live Preview toggle (device sizes, etc.), used by every Global and the Posts collection.
- Every page under `app/(frontend)/` is split into a `page.tsx` (fetches the content) and a `page.client.tsx` (renders it, and stays in sync with Live Preview) — you shouldn't need to touch either half directly, but this is why each page folder now has two files instead of one.
- `lib/schulleben.ts` — the *original* hardcoded blog data, kept only as the source for the one-time import script (`payload/seed.ts`) that populated the CMS. The live site no longer reads from this file.

## Components
- **Navbar** (`components/Navbar.tsx`) — Fixed header (stays pinned at the top of the screen while scrolling), JFK monogram + editable wordmark on the far left; the nav links and the two buttons (outline/solid) are grouped together as one cluster on the right (Relume "Navbar 14" layout style), with the flexible space living between the logo and that cluster. Collapses to a hamburger menu below the `xl` breakpoint. All content (logo text, nav links, buttons) comes from the **Header** global in `/admin`, with Live Preview support.
- **Footer** (`components/Footer.tsx`) — Address/contact, nav, legal links, and the school's three real certification badges (Schule ohne Rassismus, Sportfreundliche Schule, Zivilcouragepreis).
- **PageHeader** (`components/PageHeader.tsx`) — Shared dark hero banner used at the top of every inner page.
- **Motion system** (`components/motion/`) — `FadeIn`, `Stagger`/`StaggerItem`, `MotionLink`, `HeroImage`, `WordFadeIn` (word-by-word text reveal on mount), `TimelineLine` (animated timeline line), `ScrollHighlightText` (word-by-word text reveal scrubbed live to scroll position), and `IconPop` (icon springs into place on scroll-in) provide the site's scroll-in and hover animations (see Recent Changes below). Used consistently across every page.

## How to customize
- **Most text, images, and lists:** use the `/admin` panel — see "Content management (CMS)" above. No code editing needed.
- **Colors/fonts:** edit the CSS variables at the top of `app/(frontend)/globals.css` and the font imports in `app/(frontend)/layout.tsx`.
- **Navigation links:** use `/admin` → **Globals → Header** (see "Navigation bar" above). Only the footer's legal links (Impressum/Datenschutz) remain in `lib/nav.ts`.
- **Add a new page:** easiest way is now `/admin` → **Pages** → **Create New**, then add reusable sections — no code needed (see "Reusable sections / page builder" above). Only build a page in code (`app/(frontend)/<name>/page.tsx` + a new Global) if it needs a layout the section library can't do.

Note: the site's pages moved from `app/<name>/page.tsx` to `app/(frontend)/<name>/page.tsx` when the CMS was added (folders in parentheses don't affect the page's web address) — the admin panel now lives in a sibling `app/(payload)/` folder.
